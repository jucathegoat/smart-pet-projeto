## 🛠️ Como Executar o Projeto Localmente

### 1. Pré-requisitos
* Flutter SDK (3.22+)
* Dispositivo Android (ou Emulador) conectado

### 2. Passo a Passo
```bash
# 1. Instalar as dependências
flutter pub get

# 2. Executar o app no emulador ou celular
flutter run
```

### 3. Gerar o instalador APK
Para gerar um novo arquivo `.apk` de instalação:
```bash
flutter build apk --release
```
O arquivo gerado ficará em: `build/app/outputs/flutter-apk/app-release.apk`.
